# Official export oracle

This directory contains synthetic-only data captured from the official
Firestore emulator v1.22.0 through firebase-tools v15.28.1. It was generated by
`npm run capture:official-export` on 2026-08-27. No production project or user
data was involved.

The fixture contains four documents under `fireside_export_fixture`, including
a nested subcollection document and one large Unicode string that forces
`FIRST`, `MIDDLE`, and `LAST` LevelDB-log fragments. Its values cover empty and
non-empty containers, bytes, references, timestamps, geographic points,
non-finite doubles, negative zero, and vectors. SHA-256 of `output-0`:

`304668940b2b4a613801d6ec12df159e1b86e09b739c7219f695ae81e7392ad7`

The capture utility writes future artifacts to a fresh operating-system
temporary directory and prints that path. Regeneration does not overwrite this
fixture implicitly.
