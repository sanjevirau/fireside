produce a request-failed event and did not gate. Twodart's server-side CDN warmer
reported all five synthetic derivatives warmed on both stacks. This narrows the
difference to the missing-object response contract, not login routing, Portless
registration, Firestore, the image workflow, or a new Twodart defect.

status 404, `text/plain; charset=utf-8`, body `Not Found`, and a browser response
event rather than request failure. The same fixture separately freezes the
official GCS metadata and media forms. It was published in oracle commit
`87ad833b7a54b320450847f76eb789df08891752`.
